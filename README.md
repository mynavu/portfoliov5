# Portfolio v5

My fifth iteration of my personal portfolio website, built to showcase my projects, experience, and technical skills through an interactive and visually engaging interface.

🌐 **Live Site:** https://mynavu.netlify.app

## Features
- ✨ Interactive landing page
- 🎨 GPU-powered shader effects
- 🔠 Animated ASCII art visuals
- 📱 Fully responsive design

## Tech Stack

- **React**
- **Vite**
- **WebGL / GLSL Shaders**
- **Netlify** (Deployment)

## Running Locally

```bash
git clone https://github.com/mynavu/portfoliov5.git
cd portfoliov5

npm install
npm run dev
```
